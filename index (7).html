Comprendre les indicateurs
1
Amplitude
Durée moyenne par mission : somme des durées (fin − début) ÷ nombre de missions valides.
2
Respect du planning global
Missions complétées ÷ missions totales (tous types de RDV), sur le mois, d'après le fichier ⑤ « Toutes les missions ».
3
Atteinte objectif de performance
Temps de travail quotidien réel ÷ objectif minimum réglable (7h/jour par défaut).
4
Opérations / jour
Nombre d'opérations réalisées ÷ jours travaillés, calculés tous deux à partir d'Intervalo pour chaque technicien.
5
Taux de RDV respectés
RDV obligatoires réalisés ÷ nombre total de RDV obligatoires (fichier ④ « RDV obligatoires »). Dessous : le détail réalisés / non réalisés.
6
Infotech
Nombre de remontées terrain effectuées par le technicien (anomalie ou opportunité repérée sur site, transmise pour devis client), et part de ces remontées traitées.
Règles de filtrage par fichier
1
Intervalo
Pôle = « Hygiène » uniquement ; technicien dans la liste de référence (146 personnes).
2
Infotech
Les remontées marquées « Doublons » sont exclues ; technicien dans la liste de référence. Mois basé sur la date d'ouverture de la remontée.
3
Amplitude
Une ligne par mission ; technicien dans la liste de référence.
4
RDV obligatoires (④)
Lignes de sous-total ignorées ; technicien dans la liste de référence.
5
Toutes les missions (⑤)
Même format que le fichier ④, avec tous les types de RDV ; sous-totaux ignorés ; technicien dans la liste de référence.
