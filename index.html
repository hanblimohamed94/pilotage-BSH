Comprendre les indicateurs
1
Amplitude
Durée moyenne d'une journée de travail : écart entre le premier début et la dernière fin (colonne « Durée totale journée » de l'export), moyenné sur toutes les feuilles de temps.
2
Respect du planning global
Missions complétées ÷ missions totales (tous types de RDV), sur le mois, d'après le fichier ⑤ « Toutes les missions ».
3
RAFT — reste à faire non réalisé
Opérations Hygiène du « Reste à faire terrain » qui n'ont pas été faites : site inaccessible, refus client, problème technique, date prévue dépassée sans exécution, ou délai dépassé. Le reste à faire à venir n'est pas compté. Chiffre figé à la date d'édition du fichier ⑥.
4
Opérations / jour
Nombre d'opérations réalisées ÷ jours travaillés, calculés tous deux à partir d'Intervalo pour chaque technicien.
5
Taux de RDV respectés
RDV obligatoires réalisés ÷ nombre total de RDV obligatoires (fichier ④ « RDV obligatoires »). Dessous : le détail réalisés / non réalisés.
6
Infotech
Nombre de remontées terrain effectuées par le technicien (anomalie ou opportunité repérée sur site, transmise pour devis client), et part de ces remontées traitées.
Règles de filtrage par fichier
1
Intervalo
Pôle = « Hygiène » uniquement ; technicien dans la liste de référence (146 personnes).
2
Infotech
Les remontées marquées « Doublons » sont exclues ; technicien dans la liste de référence. Mois basé sur la date d'ouverture de la remontée.
3
Amplitude
Colonne « Durée totale journée » ; technicien dans la liste de référence. Aucune ligne n'est écartée : les durées anormales (plus de 24 h) restent visibles.
4
RDV obligatoires (④)
Lignes de sous-total ignorées ; technicien dans la liste de référence.
5
Toutes les missions (⑤)
Même format que le fichier ④, avec tous les types de RDV ; sous-totaux ignorés ; technicien dans la liste de référence.
6
RAFT (⑥)
Pôle = « Hygiène » uniquement. Une ligne compte comme non réalisée si elle a un motif (Inax, Refus, Tech), sinon si sa date prévue est dépassée sans exécution, sinon si son délai est dépassé. Technicien = colonne « Intervenant » ; les lignes sans technicien de la liste de référence sont comptées seulement dans « Toutes les équipes ».
